## 🇬🇧 English Documentation

### 📌 About the Project
**Mustaqbal Al-Yaman** is a comprehensive, modern School Management and Academic Control Web Application built using **React 18**, **Node.js**, **Express**, and **MySQL**. Designed to unify school operations and enhance communication across the educational ecosystem, it offers tailored interfaces for four distinct roles: **Admin, Teacher, Student, and Parent**. The platform provides complete management over student admissions, weekly class schedules, daily attendance, examination control with printable certificates, and tuition tracking.

### 🌟 Features
- **👥 Multi-Role Portals:** Tailored workflows and dedicated dashboards for Admins, Teachers, Students, and Parents.
- **📊 Interactive Dashboards:** Real-time visual analytics on attendance trends, student metrics, and financial records.
- **🔍 Global Quick Search:** Smart topbar search allowing instant navigation across all school records and modules.
- **🤖 Smart AI Analytics:** AI-powered modal providing live insights on attendance stability, grades, and recommendations.
- **📝 Examination & Control:** Monthly and midterm grading with automated GPA calculation and printable certificates.
- **📅 Timetable Scheduling:** Dynamic weekly period schedule management with collision-free slot distribution.
- **✅ Daily Attendance Tracking:** Live tracking of daily and period attendance with instant status logging.
- **💳 Tuition & Fee Management:** Streamlined tracking of fee installments, invoices, and payment statuses.

### ⚙️ Installation & Setup

1. **Prerequisites:**
   - Install **Node.js** (v18+) and ensure **MySQL Server** is running.
2. **Setup Backend:**
   - Open terminal in the backend directory and install dependencies:
     ```bash
     cd backend
     npm install
     npm start
     ```
3. **Setup Frontend:**
   - Open terminal in the frontend directory and launch the web app:
     ```bash
     cd frontend
     npm install
     npm run dev
     ```

## 🇾🇪 دليل الاستخدام (العربية)

### 📌 عن المشروع
**نظام مدرسة مستقبل اليمن** هو منصة تعليمية وإدارية ذكية وشاملة لإدارة المدارس والكنترول والتحصيل الأكاديمي، تم تصميمها وتطويرها باستخدام **React 18** و **Node.js** و **Express** وقاعدة بيانات **MySQL**. صُمم النظام ليسهل التواصل ويسد الفجوة بين إدارة المدرسة والكوادر التعليمية والطلاب وأولياء الأمور عبر واجهة موحدة تخدم أربعة أدوار رئيسية: **المدير، المعلم، الطالب، وولي الأمر**. يتيح النظام إدارة شؤون الطلاب، الفصول، الجداول الأسبوعية، الحضور والغياب، رصد الدرجات والشهادات، ومتابعة الرسوم المدرسية بكل كفاءة واحترافية.

### 🌟 المميزات
- **👥 نظام الأدوار المتعددة:** واجهات ولوحات تحكم مخصصة ومستقلة لكل من المدير، المعلم، الطالب، وولي الأمر.
- **📊 لوحة قيادة تفاعلية:** إحصائيات ورسوم بيانية حية لنسب الحضور اليومية ومؤشرات التحصيل والرسوم.
- **🔍 بحث ذكي وسريع:** شريط بحث احترافي في أعلى النظام للوصول الفوري لكافة الشاشات والسجلات.
- **🤖 تحليل الذكاء الاصطناعي:** تحليلات فورية لمستوى الانضباط والأداء الأكاديمي وتوصيات تربوية ذكية.
- **📝 الكنترول ورصد الدرجات:** إدارة شاملة للاختبارات الشهرية والنصفية واستخراج كشوفات الدرجات والشهادات.
- **📅 الجداول والحصص الدراسية:** توزيع وتنظيم الجداول الأسبوعية بدقة ومنع تعارض حصص المعلمين.
- **✅ رصد الحضور والغياب:** متابعة لحظية للحضور اليومي وحصص الفصول مع تسجيل الأعذار والتأخر.
- **💳 الرسوم والمالية المدرسية:** متابعة دقيقة للأقساط الدراسية، سندات القبض، وحالة الرسوم المسددة والمعلقة.
